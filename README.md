# Metro Interstate Traffic Volume Dashboard

| **Project**                  | **Description**                                                                                                                                |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Traffic Volume Dashboard** | An interactive Power BI dashboard designed to analyze interstate traffic volume and identify trends based on time, weather, and other factors. |

## Objective

The objective of this project was to develop an interactive dashboard that provides meaningful insights into traffic volume patterns and helps users understand how different factors influence traffic.

### Skills Learned

* Data cleaning
* Data transformation
* Data modeling
* DAX
* Data visualization
* KPI development
* Dashboard design
* Interactive filtering
* Business insights generation

### Tools Used

* **Power BI**
* **Power Query**
* **DAX**
* **Excel / CSV**
* **Data Visualization**

## Steps

### 1. Data Import

The traffic dataset was imported into Power BI for analysis.

### 2. Data Cleaning

Power Query was used to clean the dataset, handle missing values, correct data types, and prepare the data for analysis.

### 3. Data Transformation

Relevant columns were transformed and prepared for visualization and analysis.

### 4. Data Modeling

Relationships and required calculated fields were created to support dashboard analysis.

### 5. DAX Measures

DAX measures were created to calculate important KPIs and analytical metrics.

### 6. Dashboard Development

Interactive charts, cards, filters, slicers, and other visual elements were added to create an intuitive dashboard.

### 7. Results & Insights

The dashboard helps identify traffic patterns, peak traffic periods, and relationships between traffic volume and other contributing factors.
